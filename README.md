How to set up the repository (web UI, mobile-friendly)
1. Create the repo (if you haven't already):
Open https://github.com/new
Repository name: Gauraji-rose-day
Visibility: Private
Create repository
2. Add starter files:
Repo → Add file → Create new file
Create index.html, styles.css, script.js, README.md by pasting the provided contents and Commit directly to main.
3. Create folders (quick method use .gitkeep placeholders):
Add file → Create new file → filename: assets/background/.gitkeep → Commit
Repeat for assets/photos/.gitkeep and assets/music/.gitkeep
4. Upload images (mobile):
Open the assets/photos folder in the repo.
Tap Add file → Upload files → choose your photos from your phone (Downloads).
Select: rose.jpg, photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg, photo5.jpg, photo6.jpg → Commit.
5. Upload music:
Open assets/music → Add file → Upload files → select song1.mp3 and song2.mp3 → Commit.
6. Upload background:
Open assets/background → Add file → Upload files → select tulip.jpg → Commit.
